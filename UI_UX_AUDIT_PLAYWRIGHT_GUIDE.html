2. Playwright Configuration Master Reference ("What Is What")

Configuration Parameter Type & Default Behavioral Explanation UI/UX Audit Role
full_page bool = False When True, scrolls the full document height and stitches the entire webpage into a single image. Auditing vertical rhythm, page length, and footer placement vs. testing initial above-the-fold CTA prominence.
type & quality 'png' | 'jpeg' PNG provides lossless 24-bit output with alpha; JPEG applies lossy compression (1–100 quality). PNG is mandatory for typography and sub-pixel alignment inspection; JPEG benchmarks lightweight reporting.
animations 'disabled' | 'allow' When disabled, freezes CSS transitions, keyframes, and SVG animations at terminal states. Eliminates test flakiness from moving spinners, half-faded overlays, or pulsating status dots in CI.
caret 'hide' | 'initial' Suppresses the blinking text insertion cursor inside input fields. Prevents 500ms blinking cursor timing differences from triggering false visual regression alerts.
scale 'css' | 'device' 'css' maps 1:1 to CSS layout pixels; 'device' captures at physical hardware pixel density. 'css' enables pixel ruler measurement against 8px grids; 'device' audits Retina SVG sharpness.
clip dict {x, y, w, h} Crops capture strictly to a rectangular coordinate boundary. Targeted sub-layout inspection (e.g. score card or sticky header) without full DOM overhead.
omit_background bool = False Renders with a transparent alpha channel rather than the browser's default white canvas. Design system component isolation; audits border antialiasing and drop shadows on arbitrary backgrounds.
mask & mask_color List[Locator], str Paints solid color boxes over specified dynamic elements (e.g. timestamps or session IDs). Stabilizes visual regression testing by masking non-deterministic or volatile UI elements.
style str Injects custom CSS stylesheets into the document immediately prior to capturing the screenshot. Visual accessibility audits: draws outlines around all interactive tap targets or tests fallback fonts.
color_scheme 'dark' | 'light' Emulates @media (prefers-color-scheme: dark). Dark mode contrast compliance (WCAG AA 4.5:1), ensuring no un-themed white surfaces persist.
forced_colors 'active' | 'none' Emulates Windows High Contrast Mode. Verifies interactive buttons and cards maintain visible system outlines when custom colors are stripped.
reduced_motion 'reduce' | 'none' Emulates @media (prefers-reduced-motion: reduce). Ensures vestibular accessibility compliance by disabling non-essential motion and animated transitions.
