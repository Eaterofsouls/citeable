AI Key Vault BYOK

Register your own AI provider API keys. Keys are stored in your browser only — never sent to Citeable servers except as request headers during synthesis.

How it works: After verifying a key, it is stored in your browser's localStorage under areos_byok_vault. When you run an audit, the key is sent as an X-API-Key-<provider> header. Keys are never logged or persisted on the server.
